# ExplLib: описание взрыва (EXPL, `.exp`)

EXPL - элемент NRes (4CC `EXPL`, расширение `.exp`), который игра читает, когда деталь NDP переходит в худшее состояние или снаряд попадает в цель
(`CControlBase::CommitNdpDamageStateTransition`, `ComputeNdpDamageEffectBoundsRadius`, `ProcessActiveDamageExplosions` в `Control.dll`). На него ссылаются записи NDP,
снаряды BULL и записи предметов CTL (команда `SWAP_NDP_RESOURCE`). Парсер: `ExplFile.Read` → `ExplFile`.

## Формат

Файл всегда 792 байта (0x318): заголовок 0x18 байт и 12 слотов по 0x40 байт (ссылка на эффект: архив + имя FXID, архив всегда `effects.rlb`).
Всего в данных 104 файла первой части.

| Поле | Смещение | Смысл |
|---|---|---|
| `Field00` | +0x00 | вид урона: 1 - только эффект, 2 - урон только по объекту попадания, 3 и 4 - урон по площади в сфере радиуса `ScaleMultiplier`. В данных: 2 - 48 файлов, 3 - 43, 1 - 13, 4 нет |
| `LifeAmountOffset` | +0x04 | поправка к количеству жизни |
| `ScaleMultiplier` | +0x08 | масштаб эффекта и радиус урона по площади: у снаряда берётся как есть, для остальных объектов умножается на радиус сферы детали; все размеры FXID умножаются на него |
| `Field0C`, `Field10` | +0x0C, +0x10 | не выяснены |
| `DirectionMode` | +0x14 | куда направлен эффект (`ExplDirectionMode`): столбец матрицы детали/объекта или нормаль поверхности попадания. В данных 0 (56 файлов) и 7 (48) |
| слоты | +0x18 | слот 0 - эффект по умолчанию; слот `m + 1` - эффект для поверхности класса `m` (0..10, см. `MaterialLib.SurfaceMaterial`) |

Выбор слота: класс поверхности под попаданием `m` (байт 4 материала MAT0). Если `0 <= m <= 10`, берётся `Slots[m + 1]`; при пустом имени эффекта или без попадания -
`Slots[0]`; попадание без треугольника даёт `m = 10`. У 76 из 104 файлов задан только слот 0. Суффиксы имён эффектов (`m`, `st`, `w`, `wb/wl/wm/wt`, `al`, `an`, `s`,
`*_metal`) соответствуют классам поверхности.

Подробности цепочки «орудие → снаряд → взрыв» - [ControlLib/README.md](../ControlLib/README.md), §7.3 и §7.5.
