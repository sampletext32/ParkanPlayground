# PalLib: палитры `.pal`

PAL-файл - индексированное изображение 256 × 256 с таблицей цветов. Размер всегда 66564 байта:

| Смещение | Размер | Содержимое |
|---|---|---|
| 0x0000 | 1024 | таблица из 256 цветов по 4 байта (порядок BGRA; байт A - паддинг, игнорируется при просмотре) |
| 0x0400 | 4 | сигнатура `Ipol` |
| 0x0404 | 65536 | 256 × 256 индексов в таблицу |

Парсер: `PalParser.ReadFromStream` → `PalFile` (`Palette`, `Indices`, `SaveAsPng`). Неверный размер или сигнатура вызывают `InvalidDataException`.
В распакованных данных первой части найден один файл - `sys.lib/1_Palm_PAL.PAL`; архив `Palettes.lib` пуст, у всех текстур суффикс имени `.0`, поэтому палитры из него
не используются (см. [MaterialLib/README.md](../MaterialLib/README.md), §4).
