# ParkanPlayground: песочница для проверок и дампов

Консольный проект для разработки: быстрые проверки парсеров на распакованных файлах игры (`E:\\ParkanUnpacked` и т. п.), одноразовые дампы и сравнения.
В репозитории хранится как место для таких экспериментов; поведение `Program.cs` может меняться.

| Файл | Назначение |
|---|---|
| `Program.cs` | текущий эксперимент (часть кода закомментирована) |
| `ControlResourceDump.cs` | текстовый дамп CTL/CPT/NDP (раньше был в `ControlLib`) |
| `from_ghidra/*.c` | выгрузки декомпиляции Ghidra, на которые ссылаются заметки (`CLandscape_ctor.c`, `IMesh2_of_CLandscape_Render.c`...) |

Рабочие инструменты для просмотра данных - в [NResUI](../NResUI/README.md).
