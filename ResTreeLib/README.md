# ResTreeLib: дерево исследований (`.trf`)

![Research Tree Explorer: узлы дерева исследований, условия и что они открывают](../docs/images/research-tree.png)
*Research Tree Explorer: узлы дерева исследований, условия и что они открывают*


`.trf` - NRes-архив с деревом исследований клана; файлы лежат в `MISSIONS/SCRIPTS` (49 штук, имя клана миссии указывает на нужный `.trf`: `auto.trf`, `data.trf`,
`full.trf`...; путь хранится в `ClanInfo.ResearchNResPath` файла миссии). Парсер: `ResTreeParser.Parse` → `List<ResearchNodeData>`.

## Блоки (элементы NRes)

| Блок | Содержимое |
|---|---|
| `TRF0` | узлы: по 40 байт (`Trf0Element`) |
| `TRF1` | начальное состояние узлов, по байту (`NodeState`: доступно 0x01, исследовано 0x02, активно 0x04) |
| `TRF2` / `TRF3` | число родителей и плоский список идентификаторов родителей (предпосылки) |
| `TRF4` / `TRF5` | число и список идентификаторов узлов, которые открываются после исследования |
| `TRF7`, `TRF8`, `TRF9`, `TRFA` | пулы строк (windows-1251): короткое имя, длинное имя, справка, описание |
| `TRFB` / `TRF6` | вспомогательные данные, назначение не выяснено (в данных бывают несогласованные счётчики) |

## Узел (`Trf0Element`, 40 байт)

`ResearchCost` (0..45 в файлах), `ResearchTime` (0..150), `ViewPosX` (0..80) и `ViewPosY` (0..1500) - координаты узла в окне дерева; четыре смещения в пулах строк
(короткое имя, длинное, справка, описание), `OffsetAux_TRFB`, затем байты `TurretType`, `MainType`, `SubType`, `BuildSubSystem`, `SizeOfType`, `UpgradeLevel`.
Имена полей первых 16 байт выведены по эмпирическим проверкам на `.trf` миссий; стоимость и время явно связаны между собой и растут с уровнем улучшения.
Узлы с очень большим `ViewPosY` - в основном неименованные узлы вне экрана.

Просмотр: панель `Research Tree Explorer (trf)` в NResUI (меню `File` → `Open research .trf File`).
