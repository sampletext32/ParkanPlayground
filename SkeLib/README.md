# SkeLib: расписание атмосферы (`sky.ske`)

`sky.ske` описывает атмосферу миссии: солнце, небо, дождь, снег, молнии. Читается в `Terrain.dll` (`CAtmData::ctor`); при старой версии игра сообщает
`SunDll panic: Old version ske file`. Все 29 файлов первой части имеют версию 5 и разбираются до последнего байта. Парсер: `SkeFile.Read` → `SkeFile`.

## Раскладка

```
int -1                      начало
int version (5)
int zoneCount
для каждой зоны:
    int tag (1 = есть)
    int entryCount
    время начала, время конца   (SkeTime, 32 байта: 3 нулевых dword, час, минута, ...)
    записи (SkeEntry)
StartTime                   вероятное игровое время на старте миссии (не проверено)
Reserved20                  всегда 0
Flag24                      0/1: уходит в объект неба при создании
```

Зона (`SkeZone`) - цикл атмосферы: `ClockSpan` (23:59 во всех файлах) - интервал игровых часов, `RealDuration` - длительность цикла в реальном времени
(от 0:09 до 24:00); запись размещается на расстоянии `RealDuration.Seconds * entry.Time.Seconds / 86400` секунд от начала зоны.

## Типы записей (`SkeEntryType`)

| Значение | Имя | Событие |
|---|---|---|
| 0 / 1 | `SunStart` / `SunEnd` | создать / удалить солнце; имя `sun` или `moon` выбирает светило |
| 7 | `SkyKey` | цветовая ключевая точка неба (события не вызывает) |
| 3 / 4 | `RainStart` / `RainEnd` | дождь; `Names[0]` - фоновый звук (`atm_rain1.wav`), обязателен |
| 5 / 6 | `SnowStart` / `SnowEnd` | снег |
| 8 / 9 | `LightningStart` / `LightningEnd` | молния; `Names[0]` - имя FXID в `effects.rlb` (`env_lightning`), обязателен |

Точные значения и таблицы - в XML-комментариях `SkeFile.cs`.
