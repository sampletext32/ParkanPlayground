# Глоссарий

Термины и сокращения, которые встречаются в коде и документах проекта. Подробности - по ссылкам.

## Файлы и ресурсы

| Термин | Что это | Где подробнее |
|---|---|---|
| **NRes** | внутренний архивный формат игры (`.lib`, `.rlb`, `Land.map`, `Land.msh`...): заголовок, элементы, каталог | [NResLib](../NResLib/README.md) |
| **MSH** | меш: дерево деталей (pieces), вершины, материалы, анимация | [MshLib](../MshLib/README.md) |
| **WEA / `.wea`** | текстовая таблица материалов и карт освещения объекта | [WeaLib](../WeaLib/README.md), [MaterialLib](../MaterialLib/README.md) |
| **MAT0** | один материал в `Material.lib`: стадии (цвета, текстура) и анимации | [MaterialLib](../MaterialLib/README.md) |
| **TEXM** | текстура игры (форматы, мип-уровни, страницы атласа) | [TexmLib](../TexmLib/README.md) |
| **PAL** | палитра: 256 цветов и таблица индексов | [PalLib](../PalLib/README.md) |
| **FXID** | эффект: заголовок и компоненты (свет, звук, объекты, частицы, шлейф) в `effects.rlb` | [FxidLib](../FxidLib/README.md) |
| **EXPL (`.exp`)** | описание взрыва: эффект по классу поверхности, масштаб, урон | [ExplLib](../ExplLib/README.md) |
| **CPT** | контрольные точки объекта: якоря эффектов, дула, контакты колёс, камера | [ControlLib](../ControlLib/README.md) |
| **NDP** | повреждения: вклад деталей в жизнь/подвижность и ресурс взрыва | [ControlLib](../ControlLib/README.md) |
| **CTL** | управление объектом: лимиты, состояния, привязки, предметы, списки команд | [ControlLib](../ControlLib/README.md) |

| **BTLU / INTO / EXTO / BULL / STAT / FORT / WPNS / SUNO** | типы записей агентов: юнит, внутренний узел, внешний узел, снаряд, статический объект, укрепление, оружие, солнце | [ControlLib](../ControlLib/README.md), §4 |
| **`.dat` схема (cp)** | дерево частей объекта: шасси, башни, орудия, броня, боеприпасы | [CpDatLib](../CpDatLib/README.md) |
| **BAS (`.bas`)** | контуры основания здания | [BasLib](../BasLib/README.md) |
| **TMA (`.tma`)** | файл миссии: ареалы, кланы, объекты | [MissionTmaLib](../MissionTmaLib/README.md) |
| **SCR / FML / VAR** | скрипты ИИ: инструкции, формулы, переменные | [ScrLib](../ScrLib/README.md), [VarsetLib](../VarsetLib/README.md) |
| **TRF** | дерево исследований | [ResTreeLib](../ResTreeLib/README.md) |
| **SKE** | расписание атмосферы (солнце, дождь, снег, молнии) | [SkeLib](../SkeLib/README.md) |

## Игровая логика

| Термин | Что это |
|---|---|
| **Предмет (item)** | запись CTL: двигатель, радар, щит, батарея, ремонт, орудие, броня и т. д.; класс `CItemType*` в `Control.dll` |
| **CP0..CP15 (`common_params`)** | 16 параметров предмета; смысл зависит от типа предмета (см. [ControlLib](../ControlLib/README.md), §5.7 и §10) |
| **Привязка детали (piece binding)** | связь локальной детали с точками CPT, диапазоном анимации и значением по умолчанию; предметы ссылаются на привязки |
| **Хук (hook)** | слот таблицы CTL: список команд, который игра выполняет в определённый момент (загрузка, критическое разрушение, поверхность под юнитом) |
| **Strength (сила эффекта)** | число 0..1, от которого зависят окна активности компонентов эффекта; источник задан в заголовке FXID (`EffectStrengthSource`) |
| **Клан** | сторона в миссии; индекс клана хранится в объекте (`clan_index`); у клана свой ИИ (SuperAI) |
| **SuperAI** | стратегический ИИ клана (`ai.dll`), исполняет скрипты `.scr` |
| **Problem (проблема)** | запрос клана к ИИ (нужен рудник, защита базы, захват...), по которому ИИ назначает юнитов и выдаёт приказы |
| **Areal (ареал)** | область карты в миссии (с ареалами работает `ArealMap.dll`) |
| **LogicID** | идентификатор объекта в миссии, по которому скрипты и ИИ ссылаются на него |
| **Шаг ИИ** | выполнение ИИ клана примерно раз в 8-9 секунд реального времени: обновление, секции `_Continue`, `Problems0`, секции `_Start` (см. [ScrLib](../ScrLib/README.md)) |
| **Секция (entry)** | именованный список инструкций в `.scr`: `Init`, `Problems0`, `PBM_*_Start`, события юнитов и зданий |
| **Инструкция** | одна запись секции `.scr` (`ScrInstruction`): вызов встроенной функции, сравнение, переход, возврат, запись переменной |
| **Встроенная функция (`action_N`)** | функция движка, которую скрипт вызывает по номеру; таблица из 59 функций в `SuperAI::ctor` |
| **Ум (Mind)** | слот управляемого меха в ИИ клана; занимает мех при привязке к ИИ |
| **Схема (scheme)** | файл `.dat` юнита или здания; ИИ ведёт каталог схем (класс, уровень, прочность, множитель) и по критериям `SELECT_*` выбирает лучшую для строительства |
| **Вес объекта** | оценка силы (прочность с множителем), которой ИИ сравнивает цели и свои войска (`CalcWeightAroundPoint`, `GetProblemAssignedWeight`) |
| **Отношение к клану** | враждебный (0), нейтральный (1) или дружественный (2); у ИИ каждого клана своё, изменяется настроением 0..1 |
| **BehaviourCommand** | команда (приказ) поведению юнита: тип приказа, цель, параметры `success`, `survive`, `time`, `independence` |

## Реверс

| Термин | Что это |
|---|---|
| **Ghidra / `.i64`** | дизассемблер; проект с `Control.dll`, `World3D.dll`, `Effect.dll`, `AniMesh.dll`, `Terrain.dll`, `Behavior.dll`, `ai.dll` и другими |
| **vtable / слот** | таблица виртуальных методов интерфейса игры; в документах «слот 0x28» значит смещение метода в таблице |
| **Статус утверждения** | «проверено» (по коду и данным), «гипотеза» (данные согласуются, кода нет), «не выяснено» |
